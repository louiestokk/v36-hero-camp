# CodeCamp: Next.js och webappar

Det här projektet är en enkel kurssida för CodeCamp, där fokus ligger på att lära sig bygga moderna webappar med Next.js och React.

## Kursens fokus

- Skapa återanvändbara React-komponenter.
- Bygga sidor och navigering med Next.js App Router.
- Hämta och visa dynamisk data.
- Skapa responsiva gränssnitt för mobil och dator.
- Förbereda och publicera en webapp online.
